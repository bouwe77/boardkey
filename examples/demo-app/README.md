# boardkey demo application

Shows the epoch priority system and mute mode: a counter on the arrow keys, a
modal that takes the same keys over, and a text input that mutes the app while
you type. Open the browser console to follow which component owns the keyboard.

Run `npm run dev` from the root of the repository and open
http://localhost:38921/demo. The Vite config aliases `boardkey` to `../src`, so
changes to the library reload right away.
