# boardkey slides

The lightning talk about [boardkey](../../README.md), built with boardkey.

`F5` opens it. It is on purpose not in the header: the talk is not one of the
demos, so only someone who knows the key gets there.

The arrow keys move through the deck and wrap around at both ends, so the right
key on the last slide goes back to the first one. Each slide is its own
component in `src/`, listed in `SLIDES` in `src/App.tsx`.

Run `npm run dev` from the root of the repository and open
http://localhost:38921/slides.
